MarketPulse 위젯 정리

등록된 위젯 75개 · 유형별 · 2026-11-10 main 기준 · 위젯 화면은 로컬에서 직접 렌더해 캡처

읽는 법

  • 기준: 지금 Dashboard에 두고 마음에 든다고 한 위젯(TradingView 3종 + Sector Heatmap). 공통점은 열자마자 시각적으로 보이고, 설정·키가 필요 없고, 실시간이라는 점.
  • 화면 캡처: 로컬 서버(로컬 DB)에서 위젯을 하나씩 띄워 찍었다. 종목은 AAPL, 계정은 FRED·Polygon·FMP 키를 등록한 로컬 테스트 계정이다. 실시간 시세와 Redis가 없는 환경이라 운영과 다를 수 있는 위젯은 상태를 로컬 한계로 표시했다. 이미지를 누르면 크게 볼 수 있다.
  • 배치: 테두리 칩은 그 탭의 기본 위젯(저장된 레이아웃이 없을 때 처음 보이는 것), "위젯 메뉴 N곳"은 위젯 추가 메뉴에만 있는 곳. urlWidgetMap.js에서 자동 추출.
  • 조건: 없음 바로 동작 · 로컬 Fetcher 내 PC의 Fetcher가 켜져 있어야 함(yahoo) · 키 /settings에 API 키 등록 필요 · 로그인 내 계정 데이터.

판정

  • 기준 지금 대시보드에 두고 마음에 든다고 한 위젯
  • 유지 그대로 둬도 되는 위젯
  • 개선 남기되 손볼 곳이 있는 위젯
  • 통합 같은 데이터를 보여주는 다른 위젯과 하나로 합칠 후보
  • 삭제 후보 보여주는 내용이 빈약하거나 품질이 불확실한 위젯
  • 별도 도구 대시보드형이 아닌 작업 도구 — 따로 판단

화면 상태

  • 정상 데이터가 정상 표시됨
  • 빈약 표시는 되지만 내용이 한두 줄이거나 빈 칸이 많음
  • 빈 상태 사용자가 먼저 만들어야 채워지는 위젯
  • 오류 오류 메시지가 표시됨
  • 로컬 한계 로컬 환경이라 데이터가 비어 보임 — 운영에서 확인 필요
